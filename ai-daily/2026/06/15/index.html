2/12 Together AI 把 DeepSeek V4 Pro 推到 Artificial Analysis 速度榜前列

Together AI 称 DeepSeek V4 Pro 在其平台上成为 Artificial Analysis 输出速度和延迟双项第一，并把核心原因归结为推理系统工程，而不只是模型权重。官方 thread 指出，服务 V4 需要处理 KV cache、prefix reuse、kernels 和 endpoint profiles；后续回应也强调“speed”指单请求输出速度，而 throughput 是并发请求下的整体 tokens per minute。这个事件说明长上下文开源/开放模型的竞争正在转向 serving stack：谁能更好地管理 cache layout、batching 和硬件路径，谁就能把模型能力变成可用 agent 体验。

6/12 Agent-Native Research Artifacts 讨论把“论文”改造成可执行研究包

AlphaSignalAI 总结 Stanford、CMU 等机构的 Agent-Native Research Artifacts 论文，称传统论文把研究过程压成线性故事，会丢掉失败实验、实现细节和原始证据，导致 AI agent 难以复现和扩展。论文提出把研究成果改造成包含 claims、可执行代码、dead ends log 和 raw results 的 machine-executable artifact。作者报告 PaperBench/RE-Bench 上问答准确率从 72.4% 到 93.7%，复现成功率从 57.4% 到 64.4%。这是 AI for science 工作流的基础设施问题：未来研究对象可能首先是给 agent 执行的 package，其次才是给人阅读的 narrative。

来源𝕏@AlphaSignalAI12

7/12 LeCun 团队给 LeJEPA 学到 world model 的条件做理论刻画

AlphaSignalAI 还总结 Yann LeCun 参与的新论文《When Does LeJEPA Learn a World Model?》。论文研究 JEPA-style 表示何时能从非线性观测中恢复世界真实 hidden variables，结论是在 stationary additive-noise transition 的一类世界中，LeJEPA 的 alignment 加 Gaussian regularization 可以线性恢复 latent variables，且 Gaussian 是该保证成立的唯一分布。作者还展示该表示可支持 latent-space planning，并用从 2D 到 1024 维、pixel-based robotic control 的实验验证。这个方向重要在于，它把 world model 从经验 benchmark 推向“何时真的学到世界结构”的可证明问题。

Deep Dive 附录

Sakana Marlin

Sakana Marlin 是 Sakana AI 的首个商用产品，正式版本面向企业战略、业务企划、金融机构、咨询、智库和调研公司等高强度研究场景。它的产品承诺是：用户输入调研主题后，系统自主提出假设、收集信息、验证和组织结论，最长运行约 8 小时，最终交付结构化 summary slides 与数十页报告。Sakana 将其技术基础归结为长期推理、AB-MCTS 多模型协同搜索和 AI Scientist 工作流自动化。与通用 deep research 产品相比，Marlin 更强调“像虚拟 CSO 一样做战略调研”，并通过 pay-per-use、Pro、Team、Enterprise 等计划进入商业化。它也是 Sakana 从研究成果到日本企业落地的一次关键产品化尝试。 查看原文

Serving DeepSeek-V4

Together AI 的 DeepSeek V4 serving 文章强调，V4 的核心不是“能否支持 1M token context”这个静态规格，而是长上下文如何被推理系统实际承载。V4 的 CSA、HCA、SWA 混合注意力会产生不同尺寸、生命周期和访问模式的 KV cache；推理引擎必须分别处理 cache layout、prefix caching、local state recovery、batching 和 endpoint profile。Together 称在 NVIDIA HGX B200 bring-up 中，通过保留最可能复用的 SWA state，单节点 KV-cache capacity 从约 1.2M token 提高到 3.7M token。这对 200K-500K token 的 coding/research agent、RL rollout 和长任务轨迹尤其重要，因为成本模型会从每 token 价格转向完成整条 trajectory 的成本。 查看原文

Agent-Native Research Artifacts

《The Last Human-Written Paper》提出，传统论文的线性 narrative 会产生 Storytelling Tax 和 Engineering Tax：失败实验、被否定假设、探索分支和精确实现细节被压缩或省略，导致 AI agent 难以理解、复现和扩展研究。作者提出 ARA 协议，用 scientific logic、executable code、exploration graph、evidence grounding 四层结构组织研究成果，并配套 Live Research Manager、ARA Compiler 和 ARA-native review system。实验显示，ARA 在 PaperBench/RE-Bench 上将问答准确率从 72.4% 提高到 93.7%，复现成功率从 57.4% 提高到 64.4%。这篇论文的信号是：AI for science 的瓶颈不只是更强模型，还包括研究输出格式是否为 agent-native。 查看原文

When Does LeJEPA Learn a World Model?

LeJEPA 论文试图回答 world model 研究里的基本问题：一个 joint-embedding predictive model 到底是在学真实 world structure，还是只学到有用但混乱的压缩表示。作者证明，在 stationary additive-noise transitions 的一类世界中，LeJEPA 的 alignment 加 Gaussian regularization 可以线性恢复 latent variables；更强的是，Gaussian 是该保证成立的唯一 latent distribution。论文还给出 approximate identifiability，并说明 orthogonal identifiability 如何支持 optimal latent-space planning。实验从 2D 到 1024 维 latent，并包含 pixel-based robotic control。它的现实含义是，数据采样策略和 latent distribution 不是训练细节，而是决定 world model 是否可用于可靠规划的前提。 查看原文

North Mini Code

Cohere 的 North Mini Code 是 30B total、3B active 的 MoE coding model，Apache 2.0 发布，面向 code generation、agentic software engineering 和 terminal tasks。官方规格包括 256K context、64K max generation、最低 1x H100 FP8，可通过 Hugging Face weights、Cohere API、Model Vault 和 OpenRouter 使用。Cohere 将其包装为 sovereign developer ecosystem 的第一步：开发者和企业可以在本地、on-prem 或托管环境中运行 coding agent，不必完全依赖 proprietary subscription。官方称其 Artificial Analysis Coding Index 为 33.4，并在内部测试中相对 Devstral Small 2 获得最高 2.8x output throughput。这个发布与 Cohere 关于“技术应由使用者拥有和控制”的叙事紧密相连。 查看原文

A frontier without an ecosystem is not stable

Nadella 的文章把 AI 时代企业竞争力描述为 human capital 与 token capital 的复利系统。Human capital 包含人的知识、判断、关系、创造力和模式识别；token capital 则是企业实际构建和拥有的 AI capability。关键论点是：AI 模型会不断吸收和商品化人类与组织专业知识，因此企业不能只租用单一通用模型，而要建立可持续学习的 agentic systems，让人类反馈、任务轨迹、评价体系、私有知识和模型能力形成 cognitive loop。这个观点把“frontier model”降级为可替换组件，把“frontier ecosystem”定义为真正稳定的企业 AI 架构。 查看原文
